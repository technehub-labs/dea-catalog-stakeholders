# PCI Security Standards Council (PCI SSC)

> The PCI Security Standards Council, the industry body founded by the card networks that maintains and publishes the PCI Data Security Standard. The council governs the standard's content; compliance is enforced contractually through the card networks' acceptance regimes, under which the enterprise's payment-card processing engagement runs.
